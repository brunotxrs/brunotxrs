### 🧠 Sobre mim

Sou técnico em Desenvolvimento de Sistemas (Senac RS – 80% concluído) e estudante ativo nas maiores plataformas de tecnologia: **DIO, Alura, Curso em Vídeo e DevStar (Senai)**.

Minha jornada na programação começou com front-end (HTML, CSS, JS, React), mas logo percebi que o que realmente me move é a **união dos dois mundos**: construir interfaces bonitas e funcionais E fazer a lógica nos bastidores funcionar com precisão.

Recentemente, mergulhei de cabeça no back-end com Java e Spring Framework, desenvolvendo APIs REST completas, integração com bancos de dados (JPA/H2) e documentação automática com OpenAPI/Swagger. Paralelamente, aplico meus conhecimentos para automatizar processos reais no meu trabalho atual – como notificações de EPIs e DDS automáticos via WhatsApp.

Atualmente, além do técnico, me inscrevi para um novo curso de **Desenvolvimento de Software no Senac SC** (pós-técnico), porque acredito que conhecimento se mantém afiado com estudo contínuo e prática constante.
